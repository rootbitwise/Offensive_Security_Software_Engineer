---

#### How it is organized

- Each **season** is labeled **t1**, **t2**, etc.
- Within each season, there are thematic **blocks**.
- Within each block are the classes (**c01**, **c02**...).
- In each class, you will typically find:
- **reasoning/**    # my reasoning and notes
- **program/**      # code and exercises
- **deliverable/**  # polished deliverables
- Sometimes ASM reading and other materials

There are two types of days in my study method

- **Intake**  # day for theory, reading, and reasoning
- **Output**  # day for pure practice (code only)
